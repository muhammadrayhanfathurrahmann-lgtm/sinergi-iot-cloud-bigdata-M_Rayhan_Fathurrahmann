Gambaran umum

Sistem informasi butuh data yang akurat dan cepat untuk membantu mengambil keputusan. Tiga teknologi di bawah ini bekerja berurutan untuk menyediakan data itu.

IoT

Mengumpulkan data

Perangkat dan sensor yang tersambung internet membaca kondisi di lapangan, misalnya suhu, lokasi, dan getaran.

Keterbatasan: memori kecil, jadi tidak bisa menyimpan data dalam jumlah besar.

→

Cloud Computing

Menyimpan dan menampung data

Data dari banyak sensor dikirim ke server di internet. Kapasitasnya bisa ditambah sesuai kebutuhan.

Keterbatasan: hanya menyimpan, belum menjelaskan arti data.

→

Big Data

Menganalisis data

Data yang jumlahnya sangat besar dianalisis untuk menemukan pola atau memprediksi sesuatu.

Keterbatasan: butuh data yang terus masuk dan tempat penyimpanan yang besar.

→

Sistem Informasi

Menyajikan hasil untuk keputusan

Hasil analisis ditampilkan dalam bentuk laporan, dashboard, atau peringatan sehingga pengguna bisa bertindak.

Contoh: pengiriman vaksin yang harus tetap dingin

Vaksin harus disimpan pada suhu sekitar -20°C selama perjalanan. Jika suhu naik, vaksin bisa rusak.

  1. IoT: sensor membaca suhuSensor di dalam kontainer mengukur suhu secara terus-menerus. Misalnya suhu naik dari -20°C menjadi -12°C.
  2. Cloud: data dikirim dan disimpanData suhu dikirim lewat internet ke cloud dan disimpan, sehingga bisa dilihat dari kantor pusat.
  3. Big Data: data dianalisisData suhu dari banyak kontainer dibandingkan dengan data sebelumnya. Hasilnya berupa perkiraan bahwa vaksin bisa rusak jika suhu terus naik.
  4. Sistem Informasi: hasil ditampilkanDashboard menampilkan peringatan ke petugas. Petugas menaikkan pendingin atau mengalihkan truk ke gudang terdekat.

Mengapa ketiganya saling berkaitan

Jika tidak adaAkibatnya pada sistem informasi
IoTTidak ada data langsung dari lapangan, jadi data harus dicatat manual dan sering terlambat.
Cloud ComputingData dari sensor tidak punya tempat penyimpanan bersama dan mudah hilang atau terpencar.
Big DataData hanya menumpuk dan tidak bisa dijadikan prediksi atau dasar keputusan.

Kesimpulan

IoT mengumpulkan data, cloud computing menyimpannya, dan big data menganalisisnya. Hasil akhirnya ditampilkan oleh sistem informasi untuk membantu pengambilan keputusan. Jika salah satu tidak ada, alurnya terputus dan sistem informasi tidak mendapat data yang berguna.
